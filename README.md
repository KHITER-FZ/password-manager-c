# 🔐 Password Manager in C

A simple terminal-based password manager written in C.

This project demonstrates linked lists, binary file handling, password generation, and basic XOR encryption in C.

---

## ✨ Features

- Master password authentication
- Add new passwords
- Search passwords by website
- Update existing passwords
- Delete individual passwords
- Delete all saved passwords
- Strong password generator
- XOR password encryption
- Binary file storage

---

## 🛠 Technologies

- C
- Linked Lists
- Dynamic Memory Allocation
- Binary File Handling
- Structures
- Modular Programming

---

## 🚀 Build

```bash
gcc main.c menu.c password.c generator.c master.c -o main
```

Run the program:

```bash
./main
```

On Windows:

```bash
main.exe
```

---

## 🔒 Note

This project uses a simple XOR encryption method for educational purposes only and should not be considered secure for real-world password management.
